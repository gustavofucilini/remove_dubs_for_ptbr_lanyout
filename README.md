# Remove Crunchyroll simulcast calendar dubs
Removes the dub titles from the Crunchyroll simulcast calendar, including PT-BR dubs ("Dublagem") and localized calendar URLs (e.g. `/pt-br/simulcastcalendar`).

Fork of [Malpp/remove_dubs](https://github.com/Malpp/remove_dubs), updated to Manifest V3.

## Install (unpacked)
1. Open `chrome://extensions` and enable Developer mode.
2. Click "Load unpacked" and select this folder.
